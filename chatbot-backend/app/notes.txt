To run this project 

activate the venv
cd /Users/harikrishnann/Personal/litellm-chatbot
docker compose up --build        # add -d to run in the background



What	URL
Chat UI	http://localhost:3000
Backend health and metrics	http://localhost:8000/health, http://localhost:8000/metrics
LiteLLM gateway	http://localhost:4000
Prometheus	http://localhost:9090
Grafana (dashboard "SmartRoute")	http://localhost:3001



Useful commands:

docker compose logs -f backend    # watch request logs (route, provider, latency)
docker compose down               # stop everything
